# tx-01-45 Virtual Device E2E 场景与失败判据

日期：2026-10-16。场景在实现前定义；唯一一次统一验收已执行，结果 FAIL（Native 链接失败，实机阶段 NOT_RUN）。详见[验收记录](tx-01-45-results.md)。

本次完整目标为自有 ABI、NEVER/root 常驻、原生 Join、A/B V2 输入、participant lifecycle 和恢复的最小生产闭环。依据现行规范，分析与实现期间零测试；全部代码完成后仅经一个统一入口执行一次构建及真实游戏验收。失败不自动重跑。

## 场景顺序

1. 用户提供已授权的隔离 Offline/local-co-op run，初始只有 A、Online roster 为空。确认具体注入、游戏输入、换房、死亡/复活、退出操作的范围；未授权不执行。
2. 启动 coop-active，安装同一 owner 的 Hook，pin DLL，构造及注册 B 设备一次。原生 JoinControl 触发普通 selector-row Join，确认实际 B Main Player 发布、A0/B1、正 K 和 exact pair。
3. A 的真实移动/射击经 loopback，B 按脚本送不同方向的移动/射击；观察两个 Player 的 consumer 与 world witness，不能只以 synthetic query 返回值判断隔离成功。
4. 覆盖 V2 held、Bomb/Item/Pill/Drop 显式 edge、重复 command、重复 query、非法 canonical、过期 command、旧 generation envelope 与缺输入。每个 participant 每 tick 最多 Resolve 一次，缺输入立即中性，世界继续一次更新。
5. pause/resume、loading/换房、死亡/复活或对应用户可操作的正常边界，验证临时绑定失效、首个合法 current 的显式 edge、不复活旧 previous/edge。未发生的场景记 NOT_OBSERVED。
6. 最后执行 `conflict-b`，由同 sequence 不同内容触发 B-only retirement，验证冲突 pending 不应用、原生移除消费 vector 引用恰一次、exact pair 缺席、B Main Player 已退出、root/对象/control/DLL 常驻；A 在唯一重绑后继续。普通 `retire-b` 不能替代冲突场景。
7. 用户执行已授权的 menu/run teardown，再正常 shutdown。逐个比较 Hook 原始字节，确认回调排空、pair 缺席和 DLL 仍驻留。恢复不确定时停止，不卸载、不重注入。

## 失败判据

- 原始指令/ABI/对象身份不符、非主线程修改、未知 normal-reader guard、绑定冲突：输出中性并记录具体失败。
- base ctor 或 Init 后资源不满足实际 n_bind、control 构造不完整、K 非正或不唯一、insert 后 exact pair 不唯一：不发布 gameplay；构造后不释放、不重试。
- Join query 事件把 NOT_CALLED 伪装为 false；query 消费 sequence；同 session 再次 actual-create；仅 bind 返回即声称发布成功：失败。
- A 绕过 canonical/queue，B 输出回流物理采样，未知受控 identity 透传物理输入，跨 participant 清理状态：失败。
- 缺输入阻塞 Authority、重复 Resolve/world update、旧 edge 跨 target/generation 复活、首 tick 合法显式 edge 被 previousInvalid 吞掉：失败。
- vector strong 二次扣减、调用旧 FinalRelease、释放已构造对象/control/base、卸载 pinned DLL：失败。
- 事件环覆盖/半发布、恢复字节不符、在途回调未排空、缺少 world witness、场景未观察：不能记 PASS。

## 产物

统一入口创建一个新的 artifact 目录，保存 invocation.json（场景、参数、确认的操作范围）、build.log、events.jsonl（输入/Resolve/query/Join/lifecycle/witness）、operations.jsonl（用户操作及阶段标记）、result.json 和 restoration.json。状态只有 PASS、FAIL、NOT_OBSERVED、NOT_RUN；整体 PASS 要求必要场景都有实际证据，人工声明不能替代 native/world 事件。所有判断给出可读 event sequence 引用，不计算或校验哈希。

不主动制造 OOM、C++ EH、AV 或 worker 竞争，不声称完整异常/并发恢复。原生 Join 创建/发布的用户假设保留，实机结果单独记录。
