E2E 的录制上下文顺序原先不够明确，现已写明：S8 先正常关闭 primary，再按故障分别建立新录制，真实 Closed 后才继续；S9 另建健康录制、重新取得当前 Player 读取依据，专门观察正常 stop 与 Host 继续。S7 明确只暂停 DLL 自有 raw reader，不暂停游戏线程。
