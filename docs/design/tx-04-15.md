## 实现前的失败模型与统一验收范围

以下在实现前确定，用于本tx最终统一E2E，分析／实现期间不运行测试，也不新增单元测试。

- 来源：混合session／epoch、不同普通窗口、独立Render／ActualCall借用普通tick、缺域、Partial、空payload、异常或超预算都不能伪装完整世界。完整成员和部分枚举分开，缺席不推断删除。
- 身份：地址／seed／Index不能成为网络key；同源主体反复出现须同ID，跨房保留逻辑对象，池槽复用和新use换ID；Morph只更新shape revision；跨run／epoch引用不得误连。Player身体和Entity用同一ID，参与者与控制组独立。
- 值：缺字段、Unknown、Null、Empty、NotApplicable、Unavailable、NotCaptured、ReadFailed、Nonfinite、Truncated与明确Deleted分开；u64／i64及128位标志不经过浮点；不发送指针、vptr、平台／设备handle。未知语义不能自动标为支持。
- 模型：资源路径／内容版本／图层／姿态／相机／过渡独立表达；状态字段与可丢表现事件分开，玩法随机内部状态只留房主。所有目录成员有归属理由和应用任务，不能把setter当客户端RPC。声明Mod不等于任意Mod兼容。
- 版本：B→T完整差异必须从不可变B重建；值回到B、最终删除、重复／旧目标、错误基线、同版本冲突、跨场景均需明确结果，不能拿当前模型直接patch。
- 协议：未知版本／kind／flags／reserved、长度／深度／节点／字节／字符串／片数超限、重复字段、非法UTF-8、非有限数、重复／冲突分片、乱序／丢片／过期／候选溢出均明确拒绝；不发布半包。协商失败、未知required capability与未知资源分别报告。
- 确认：输入处理ACK、收包进度、模型解码完成、原生Applied ACK互不等价。事件按scene／event ID去重、水位抑制重播、版本依赖和到期处理；可靠控制有序有界、跨lane依赖显式携带。

统一验收用一次新游戏采集11域真实值和独立scope，通过正式C++adapter／codec及独立Rust解码核对，再对这些真实模型执行基线／Delta／分片／错误注入。09—14已通过且不受影响的玩法清单不重复执行。临时材料成功后清理；失败连续修复续测。

## 复制合同与工程入口

正式纯值库为`mod/src/replica/`，由DLL工程链接；`Capture`接收正式观测consumer交付的自有值，不读取游戏或录制文件。`CaptureRows`是相同adapter的文件入口，供E2E使用。15不安装新Hook、不改输入调度或原有采集，也不接入网络线程／原生应用；16负责游戏角色接线，21—22负责实际每Peer传输／重传／恢复。

`model.h`的Scope将session、connection、run、floor、dimension、room、scene分别作为u64代次。Authority调用者分配这些代次，source epoch/run绑定在Registry首次采集时冻结；新run创建新Registry。Key为`(run,space,id)`，session来自消息Scope；14个身份空间沿公共观测域编号。单调分配的id不复用，source local/use只在进程内映射，不进入wire；同一身体在Entity、Player、房间关系中使用同一key。Morph保留id并携带shape revision，new use分配新id，重连换connection，不重新解释旧对象。Registry最多262,144项，耗尽抛显式错误；不回绕。

普通模型的11个component分别保留domain、version、coverage、reasons、membership_complete、ownership、capture和state。capture携带真实source scope／sequence／tick／phase／来源版本／event watermark。完整普通模型必须来自同session／epoch／run、同tick／outer／owner、mutation不变的一个窗口；缺域／Partial仍可表达为`publishable=false`的诊断DTO，但不能作为可应用Baseline或Delta。跨域引用带component／required_revision及原source scope，不将非同时来源拼成原子世界。独立Render／Lifecycle／Transition／PlayerPost／ActualCall使用Component消息，无普通tick、自己的source scope及明确依赖，不能升格为完整世界。Query的实际phase沿来源记录，不按函数名补造。

每项成员归属由`mod/tools/gen_replica_catalog.py`生成到产品`replication-catalog.json`并嵌入库。原目录每行均保留；`ReplicatedState`复制公开最终值、结构与引用，`PresentationEvent`只表达允许的瞬时音画结果，`AuthorityOnly`保留房主操作／玩法裁决／随机内部状态，`ClientLocal`属于本地输入／窗口／设置。重复语义优先规范Entity成员；不丢弃原目录行。每行有理由、单位／参数、原schema和应用tx；结构值继承其域，未登记成员明确Unsupported。回调及目录的unexposed也保留独立归属；目录覆盖不等于运行支持。

应用责任：18 Room/Grid；19 Entity；20 Player／控制组／多身体；23跨房与成员事务；24楼层／探索／离房保存；25规则／随机结果；26换层／重构；27 HUD／音画／声明Mod；28生命／结局；29全部原版内容；31合法保存与访客进度。持久写入操作仍是AuthorityOnly。全部模式／原版类别可用同一全域值合同表达，不缩成少量变体profile；实际native applier能力目前为空，后续完成后逐类声明。

值树区分字段缺席、显式null、空数组／对象和带status的Unknown／Null／Empty／NotApplicable／Unavailable／NotCaptured／ReadFailed／Nonfinite／Truncated。删除在Delta的完整最终component替换和显式Deleted项中表达，部分成员集合不允许产生删除。i64／u64和bits128十进制字符串保持原精度，二进制整数也有独立有符号／无符号标签。无法安全映射的引用保留Unresolved／NotCaptured／UnsupportedTarget／Retired／AmbiguousReuse／CrossEpoch，不把未知裸地址补成0。

Sprite转成resource_pose：逻辑ANM2路径、内容版本要求与独立资源状态，并保留main／overlay／layer／动画／颜色等实际公开姿态字段；Camera、RoomTransition及Entity空间状态仍在各自成员项中，不调用本地FSM。资源初始Unverified，缺路径Unavailable，不以图像关联／loaded／同路径声称GPU准备成功。换图／shader／完整轨道／context／Lua借用寿命／失败退休按17的专项资料执行；不可观测项继续保留缺口，模型不补造值。资源／Mod版本按显式版本声明协商，不读文件摘要。

## ICSR v1线格式与接收语义

全部整数为小端。24字节头依次为`ICSR[4]`、version:u16=1、kind:u8、lane:u8、flags:u16=0、reserved:u16=0、payload_length:u32、sequence:u64。序号非零；消息／模型／输入／事件／控制分别计数。长度、版本、lane、保留位、kind及正文schema严格检查。

正文是有类型值树，不是观测JSON文本：tag:u8的0=null、1=false、2=true、3=u64、4=i64、5=IEEE754 f64、6=UTF-8 string、7=array、8=object。字符串为u32字节数+字节；array为u32数量+值；object为u32数量+重复的字符串key（不带tag）及值。对象key按UTF-8字节排序编码，重复key拒绝。所有浮点有限，UTF-8严格合法，无尾随字节。值状态使用模型显式字段；Nonfinite是缺失状态标签，不把NaN放进f64。

| Kind | Lane | 正文责任 |
| --- | --- | --- |
| 1 Hello／2 Welcome | Control=2 | capabilities包含protocol/model、目标版本、required/supported、11域、类别、独立native_appliers、Mod／资源版本与预算；Hello带Client角色／nonce，Welcome回显client_nonce并带Authority角色、server_nonce、分配的Scope和participant |
| 3 Baseline | Recovery=3 | 完整普通模型、revision、场景、成员与引用、event watermark；不声称native_applied |
| 4 Delta | State=4 | scope、base、target、header、replace、remove；从不可变base完整重建target |
| 5 Event | Presentation=5 | event_id、server_tick、required_state、expires_tick、白名单kind与自包含展示参数 |
| 6 Control | Control=2 | control_id、required_state、白名单operation与参数；不开放函数／地址RPC |
| 7 InputAck | Input=1 | participant、generation、input_sequence、processed_tick，仅表示Authority处理进度 |
| 8 AppliedAck | Control=2 | snapshot、event watermark；调用者完成原生提交后才能创建 |
| 9 Error | Control=2 | code、recoverable、detail；资源失败／版本错误／缺基线与预算错误有不同code |
| 10 ReceiveAck | Control=2 | transfer、received_parts；仅表示分片到达 |
| 11 Component | State=4 | 独立来源domain/schema/capture_kind/source_scope/required_state/coverage/value |
| 12 Input | Input=1 | participant、generation、input_sequence、target_tick、movement/aim、held/edge；复用core::Valid的canonical V2语义 |

状态Delta采用完整component最终值替换，保留对象／字段的最终缺席；这是正确性优先的编码，不宣称已做稀疏字段优化。`Difference(B,T)`不依赖上一发送包，`Reconstruct(B,D)`从B开始，不能patch任意current。ModelWindow接受完整DTO，拒绝缺基线／旧场景／同版本冲突，重复和旧目标不覆盖新目标。只保留两份有界基线；失去引用基线需恢复。Stage成功只表示DTO候选可用，不能用作Applied ACK，原生部分应用／停显／恢复在17—22接线。

瞬时事件kind仅sound/flash/particle/text/animation/shake。EventWindow按场景、事件ID／水位、tick、required_state和过期时间判断，最多4,096个已播放ID，不替调用者执行原生效果。ControlWindow有序、幂等、校验版本依赖并保留256项冲突历史；早到依赖由调用者有界缓存或重传，15不伪造已交付的网络可靠层。收包、解码、模型重建、原生应用和输入处理确认始终分开。

默认单模型32MiB、1,048,576节点、深度64、单字符串2MiB；握手预算只能收紧。分片头32字节：`ICRF[4]`、version:u16=1、reserved:u16=0、transfer:u64、total:u32、index:u32、count:u32、payload_length:u32。默认datagram=1,200、最多32,768片、每Peer两候选、5,000ms超时；非末片固定1,168正文字节，末片几何严格核对。乱序／相同重复可接纳，冲突删除该候选；丢片／超时不发布、不Applied ACK。网络和原生工作不在重组器内执行，Authority不等待慢Peer。

## 统一验收入口

`scripts/accept-tx-04-15.ps1`统一构建和E2E。新游戏只建立四参与者／至少五身体的源数据，采集11域稳定窗口及独立scope，创建／移除一个实际Pickup使成员发生变化，然后正常停录／退休／退出。`replica-contract.exe`调用正式库，将真实数据投影、编码、解码、分片重组、构造与重建Delta，注入错误验证失败合同。Rust另写规范解码器逐值比较wire，并从原始记录逐叶核对复制字段／归属／引用／成员／姿态和控制组；不只比较包数或模型自身往返。

`-Stage Reduce -TemporaryDirectory <原目录>`只归约已完成实机场景且环境已恢复的材料。已通过的codec／独立解码组会逐组保存并复用；修改正式模型／codec后加`-RetestContract`使受影响的合同组重新执行。只修改离线归约器时沿用实际数据，不再次启动游戏。采集／harness影响到的场景需继续实机，分别提示，无需再问授权。正常入口成功默认清理；Reduce后由操作者关闭材料句柄并按已核定的out子目录清理，没有永久tx artifact。
