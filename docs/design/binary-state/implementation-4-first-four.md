## 布局与后续接线

当前整数布局版本 **27**。24 是初轮仅更正原生归属的中间版本；25 增加 Knife 的 K4 六字段／24B 线状态；26根据续研与主审修正字段语义和证据等级；27将六段空白的新扫描证据与限制写回布局注释，不改变其UNKNOWN分类。生成器、共同 codec 和 Hook 未作修改；本轮改动由 `entity-classes.json`、`entity-effect.json` 和版本源驱动。

- Knife 的 `+0x504/+0x508/+0x50C/+0x510/+0x514/+0x518` 依次为子刀分裂时保存的父刀距离、子刀相对角度、局部偏移X／Y、本刀分裂触发距离和碰撞方向角。Init、两个分裂helper、Update和HandleCollision互证类型及用途，证据升级“已核”。K4继续保留六个f32／24B和有限值检查，不虚构倒计时，也不在Client重演分裂或碰撞。原名称 `knife_tail_render_angle` 更正为 `knife_tail_collision_angle`；该更名不改变字段顺序和宽度。
- Slot 的 `PersistentGameData*` 与 Projectile 的 `function*` 只有本地意义。第10步不采集其地址，第13步不把Host地址恢复到Client，也不通过这些指针重演捐款、派奖、更新或插值回调。Slot最终奖励Sprite仍按已有独立块同步。
- Effect 传播和生成请求留在Host，Client按最终成员、公共状态和Sprite显示。`+0x444` 具有反向登记，不能浅拷贝或擅自以裸借用处理；本轮未新增其Client写入路径。两个Vector归属纠正不等于允许执行Spawn helper。
- 正式Host采集／Client安装仍由第10／12／13步接通；本次不是运行中的同步行为验收。
