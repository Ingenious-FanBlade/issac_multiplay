### 0.3 术语

后续文档和代码注释统一使用下表的术语。

| 术语 | 含义 |
| --- | --- |
| 布局源 | 第 1 步定义的唯一数据文件，描述每个原生类型的字节归属和状态布局 |
| 布局编号 | 一个具体类型布局的编号，也就是记录头里的类型标识 |
| 布局版本 | 整个布局源的整数版本。两端必须相同，不计算哈希 |
| 状态块 | 一个类型状态中按变化频率划分的连续片段，是变化检测和增量发送的最小单位 |
| 变化版本 | Host 为每个块记录的最后一次变化的版本号 |
| 已确认版本 | 某个 Peer 通过 AppliedAck 确认已原生安装的版本 |
| 状态帧 | 一次发送的单位，携带从已确认版本到目标版本之间所有变化过的块 |
| 成员序号 | 成员表中的下标，取代每帧重复携带 key／use／shape |
| 影子状态 | Client 保存的、按布局排列的最新已接受状态 |
| 变体臂 | 同一原生类按选择字段（例如 Effect 的 variant）分出的布局，各有布局编号；选择字段的变化属于形态变化 |
| 帧锚点 | 不随帧变化的帧基准或到期帧，用来代替随帧递增或递减的计数 |
| 展示时钟 | Client 最近已应用 world 帧头中的 game_frame，用来由帧锚点还原计数 |
