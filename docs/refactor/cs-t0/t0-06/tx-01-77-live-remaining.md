# tx-01-77：剩余正常场景与独立故障取证

日期：2026-10-19。用户要求继续测试，并确认：可在采集启动后再拾取产生跟班的道具；本轮纳入受控消费暂停和控制器失联；允许控制器增加 IPC 取证元数据并仅纯编译控制器，Native/Helper 沿用冻结产物。

目标是在一次统一执行中获取跟班实际创建/Init 与完整字段证据，补充人工标记的正常暂停/恢复、普通换房及 run 退休材料；在正常采集进程中只暂停自有控制器的 world-reader 线程一次，在最后一个全新进程终止本执行器创建的控制器并独立读取恢复字节与发布关闭状态。全量 replay 继续排除，已完成的离线用例不重跑。前次报告只读，历史 PASS 标明来源，不当作本轮重测。

## 先列出的失败方式与处理

在实现独立观察器前登记以下失败方式；不新增单元测试或独立试跑。

| 失败方式 | 本轮处理与证据 |
| --- | --- |
| PID 被复用、进程路径或创建时间不符 | 持有只读游戏进程 handle，检查实际路径和 FILETIME；不读取不对应的进程，不执行故障动作 |
| 恢复目录缺项、重复 RVA、宽度非法、RVA 越界或注入前已有未知补丁 | 限定 70 个唯一目标及 1–16 字节，保存本次注入前实际值；非指针入口/调用指令对照既有原字节，4 字节函数指针须落在当前映像，原生安装事务仍核对其已知目标；冲突停止，不覆盖。指针不跨进程按旧绝对地址比较 |
| ReadProcessMemory 失败或短读 | 保存错误，恢复不确认；不改内存保护、不写游戏、不盲目继续 |
| 元数据缺失/部分写入、错误 session/nonce/PID/尺寸/版本或意外 mapping 名 | 首次故障动作前完整校验，外部仅 FILE_MAP_READ；读失败不触发暂停或终止 |
| mapping/头在恢复时变化，事件被覆盖或事件槽的 published 前后不同 | 保存原始头与实际状态；只用稳定关闭后的记录作恢复依据，不能据不稳定值 PASS |
| 找不到唯一 world-reader、线程属于其它进程或本来已暂停 | 不暂停；若 SuspendThread 返回既有暂停数则只撤销本次增加的一次并记录失败 |
| 暂停期间异常、用户中断或读取失败 | finally 恢复本次暂停计数，保留暂停/恢复结果；不暂停游戏或其它线程 |
| 恢复线程失败或控制器退出 | 记录不能确认恢复，停止后续实机操作；不增加盲目 Resume/kill/reinject |
| 暂停没有触发背压、游戏本身暂停或 tick 未推进 | 不把动作已执行等同故障测试通过；保存 before/during/after 独立值，判定只覆盖实际现象 |
| 失联时进程已换/已退出、collector 没有活样本或有预存错误 | 不终止其它进程；只对持有的 Popen 子进程实施一次故障 |
| 失联后原生恢复超时、70 槽不符、callback 未收敛或模块消失 | W13 不得 PASS；不调用 helper 再修复、不强制卸载、不重注入、不终止游戏 |
| 控制器被终止后文件截断、仍有 READY/READING 槽或事件未消费 | 不伪造正常 final drain；独立只读保存关闭头、未消费批次的有界值副本和恢复事件，区分发布关闭与文件完整性 |
| Native 失联错误不是既定 Publication 或出现额外 world 错误 | 保存实际错误并判失败，不用正常停止成功替代失联证据 |
| 熟悉场景只覆盖部分预算/读取故障或生命周期 | 保留部分证据与 NOT_COVERED，不用一次消费暂停概括 W12 全部故障，也不以普通换房代替 Morph/Restore/Replace |

## 取证设计

控制器在注入前写出 `observation-metadata.json`：game/controller PID 与创建时间、session/nonce、coop/world mapping 名称及版本。只增加产物，不改 IPC 布局、原生 Hook、调度和关闭逻辑。外部观察器只读 mapping，绝不写 consumed、槽 state、stop 或游戏字段。

外部进程读取在注入前、已安装、失联恢复后三个阶段的 70 槽原始字节；RVA/宽度来自已保存正常恢复目录，实际地址由当前游戏 image base 加 RVA 得到。失联后要求独立观察到 coop restored/pinned、world enabled=0/closed=1/callbacks=0、19 个进入返回计数收敛、发布计数稳定、原字节恢复和 DLL 仍驻留。失联允许未消费尾部，不伪造控制器已落盘。

所有运行时查询、暂停、终止、样本分析都在同一个最终统一执行内进行。实现和纯编译期间不访问游戏，不运行测试。运行后在本目录追加实际结果与未覆盖项。

运行历史：tx-01-77 主模块识别注入前 FAIL；用户确认修正后，tx-01-78 因错误排除三处 USER32 IAT 在注入前 FAIL。两份失败保留。用户随后确认逐槽 owner 修正，tx-01-79 完成一次整体运行，21 PASS / 0 FAIL / 12 NOT_COVERED，见[实际结果](tx-01-79-e2e-results.md)。本设计最初“4 字节指针须落当前游戏映像”遗漏 IAT，现以[每槽 owner 规则](tx-01-79-iat-observer-fix.md)更正。
